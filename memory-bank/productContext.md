# Product Context: f/28 Production Agency Website

## Purpose
The f/28 website serves as a digital portfolio and showcase platform for a production agency specializing in photography and retouching. It aims to present the work of 7 talented photographers/retouchers in a visually stunning, professional manner.

## Problems It Solves
1. **Portfolio Presentation**: Provides a centralized, professional platform to showcase high-quality photography work
2. **Client Discovery**: Allows potential clients to explore different photographers' styles and portfolios
3. **Brand Credibility**: Demonstrates partnerships with major brands through logo display
4. **Contact Facilitation**: Makes it easy for clients to get in touch with the agency

## How It Works

### User Journey
1. **Landing**: User arrives at homepage and sees full-screen photographer showcases
2. **Exploration**: User scrolls through 7 sections, each highlighting a different photographer
3. **Deep Dive**: User clicks "SEE ALL PORTFOLIO" to view a photographer's complete work
4. **Portfolio Viewing**: User browses masonry grid of images, clicks for full-size view
5. **Contact**: User accesses menu for contact information or visits About page

### User Experience Goals
1. **Visual Impact**: Immediate impression through large, high-quality images
2. **Smooth Performance**: No lag or freezing despite heavy image content
3. **Easy Navigation**: Intuitive menu and clear call-to-actions
4. **Professional Feel**: Clean, modern design that reflects agency quality
5. **Mobile Accessibility**: Fully responsive across all devices

### Key Interactions
- **Scroll Navigation**: Smooth scrolling through homepage sections
- **Menu Toggle**: Fullscreen menu with background overlay
- **Image Gallery**: Masonry grid with lightbox functionality
- **Portfolio Navigation**: Direct links to individual photographer pages

## Target Audience
- Potential clients seeking photography/retouching services
- Brands looking for production partnerships
- Industry professionals exploring talent
- Photography enthusiasts

## Brand Identity
- **Name**: f/28 (photography aperture reference)
- **Style**: Modern, minimalist, professional
- **Color Scheme**: Black and white with high-contrast imagery
- **Typography**: Clean, sans-serif fonts with generous spacing
- **Visual Language**: Large imagery, bold typography, ample white space
