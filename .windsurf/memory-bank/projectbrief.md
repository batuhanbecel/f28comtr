# Project Brief

## Project Overview
f/2.8 Production - A modern photography portfolio website showcasing professional photographers and AI-based creative work.

## Core Requirements
- Next.js 16.1 with App Router and Static Site Generation
- TypeScript with strict typing
- Tailwind CSS for styling
- Responsive design across all devices
- Modern, minimalist aesthetic with smooth animations
- Fast performance and optimized images

## Key Features
1. **Split Landing Page**: Two-section homepage (Production / AI Based)
2. **Production Section**: Traditional photography portfolios with photographer profiles
3. **AI-Based Section**: Showcase for AI-generated creative work
4. **Portfolio Pages**: Individual photographer portfolios with masonry grid layouts
5. **About Page**: Company information and contact details
6. **Modern Navigation**: Slide-in hamburger menu with smooth animations

## Technical Stack
- **Framework**: Next.js 16.1 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Image Optimization**: Next.js Image component
- **Deployment**: Static site generation (SSG)

## Design Principles
- Clean, modern aesthetic
- Smooth transitions and animations
- Typography-first approach with consistent system
- Glass morphism effects where appropriate
- Mobile-first responsive design
- Performance-optimized image loading
